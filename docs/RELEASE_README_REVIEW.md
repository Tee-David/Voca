# README Release Review

Review the rendered README on the clean candidate, not only the Markdown source.

- [ ] Opening sentence explains Voca without requiring stack knowledge
- [ ] Problem statement is concrete and concise
- [ ] Local-first claim matches tested behavior
- [ ] Feature list contains no roadmap-only capability presented as complete
- [ ] Architecture diagram is readable on desktop and mobile GitHub
- [ ] Quickstart is verified from a clean environment
- [ ] No setup step requires maintainer-only infrastructure without saying so
- [ ] Security and privacy links are prominent
- [ ] Responsible-use language is clear without sounding like a piracy tool
- [ ] Maintainer attribution is correct
- [ ] License section matches the final selected license/model notices
- [ ] No private URLs, screenshots, user data or deployment details appear
- [ ] All relative links resolve in the public repository
- [ ] Release status wording is updated when the candidate becomes public
